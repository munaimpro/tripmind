
# UI Design System

## Design Style

Modern

Minimal

Premium

Elegant

Clean

Travel-focused

## Colors

Maximum 3 primary colors.

Gradients may be used.

Avoid excessive colors.

## Components

Reusable components only.

Consistent spacing.

Consistent border radius.

Soft shadows.

Smooth hover animations.

Responsive.

Mobile-first.

## Typography

Readable.

Modern.

Consistent hierarchy.

## Images

Use Next.js Image component.

## Completed Pages

Do not redesign.

- Home
- Explore Trips
- Destination Details

Only integrate backend APIs.

## New Pages

Follow the existing design language.

- User Dashboard
- My Trips
- Saved Trips
- Profile (By session user id. Same page for both admin and user)
- Admin Dashboard

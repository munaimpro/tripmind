
# Coding Rules

## TypeScript

- Use strict TypeScript.
- Never use any.
- Prefer interfaces.

## React

- Reusable components only.
- Keep components small.
- Follow existing folder structure.

## API

- Use Native Fetch API.
- Do not use Axios.
- Do not use TanStack Query.
- Keep API logic inside reusable service files.

## UI

- Do not redesign completed pages.
- Maintain existing spacing.
- Keep responsive.
- Maximum 3 primary colors.
- Reuse existing components.

## Backend

- Keep REST architecture.
- Proper error handling.
- Reusable helper functions.
- Consistent API response format.

## General

Modify only required files.

Never duplicate existing logic.

Always preserve project architecture.

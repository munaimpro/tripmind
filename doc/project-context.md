
# TripMind AI

## Project Overview

TripMind AI is a modern AI-powered travel planning web application.

Users can

- Explore travel destinations
- View destination details
- Generate AI-powered travel plans
- Optimize travel budgets
- Save favorite trips
- Manage personal trips
- Leave reviews

## Tech Stack

Frontend

- Next.js App Router
- TypeScript
- Tailwind CSS
- Better Auth
- Native Fetch API

Backend

- Express.js
- TypeScript
- MongoDB
- Better Auth JWT
- Gemini AI

## AI Features

1. AI Smart Travel Planner

    Generate personalized travel itineraries using

- destination
- budget
- duration
- travel style
- group type
- interests

2. AI Budget Optimizer

    Optimize an existing AI-generated trip according to a new budget.
